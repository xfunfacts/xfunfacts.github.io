Babe Ruth Hit the First All-Star Game Home Run xFunFacts

The fact

[xFunFacts] Babe Ruth hit the first home run in MLB All-Star Game history during the inaugural event in 1933.

Babe Ruth made baseball history by hitting the first home run in the inaugural Major League Baseball All-Star Game in 1933. Already one of the sport's greatest stars, Ruth added another unforgettable milestone to his legendary career with that powerful swing. The annual All-Star Game has since become one of baseball's most celebrated traditions, bringing together the league's best players for a showcase event. Ruth's historic home run remains one of the defining moments from the game's earliest years.

Did you know?

Ruth's 1933 All-Star Game home run came at Chicago's Comiskey Park and helped provide one of the defining moments of the newly created exhibition.
